# TRON (Nile testnet) deploy toolchain

TRON is not an EVM chain — no `eth_*` JSON-RPC, so Hardhat's `networks` config
(`../hardhat.config.js`) can't target it. This directory is a separate
[TronBox](https://tronbox.io) project, deliberately isolated from the root
Hardhat toolchain (its own `package.json`/`node_modules`) to avoid dependency
version conflicts with `hardhat-toolbox`.

## Setup

1. `npm install` (in this directory).
2. Get testnet TRX for your deployer address at
   https://nileex.io/join/getJoinPage — needed for deploy gas.
3. Set `TRON_NILE_DEPLOYER_PRIVATE_KEY` in the repo root `.env`
   (see `../.env.example`).
4. `npm run migrate:nile` (or `npm run deploy:tron-nile` from the repo root).

## How it fits together

- `contracts/` is a **symlink** to `../contracts` (created via `ln -s`), not
  a copy — `SubscriptionManager.sol` and `contracts/mocks/MockUSDC.sol` have
  one real source location. TronBox requires `contracts_directory` to live
  inside the project, which is why the symlink exists instead of pointing
  the config directly at `../contracts`.
- `contracts/Migrations.sol` is a standard TronBox/Truffle bookkeeping
  contract (tracks which migrations have run) — Tron-tooling-only, not part
  of the application.
- `build/contracts/*.json` (git-ignored, regenerated by `tronbox compile`)
  is the source of truth for the JSON ABI used by `scripts/keeper.tron.js`
  and (copied once, as plain `.ts` constants) by
  `frontend/src/abi/*Tron.ts` — a separate compile pipeline from Hardhat's,
  so kept as its own source of truth rather than hand-ported from the
  ethers-flavored ABI strings used on the EVM side.

## Redeploying

After any contract change, re-copy the compiled ABI into the frontend:

```js
node -e '
  const fs = require("fs");
  const manager = require("./build/contracts/SubscriptionManager.json");
  const usdc = require("./build/contracts/MockUSDC.json");
  fs.writeFileSync("../frontend/src/abi/SubscriptionManagerTron.ts",
    "export const SUBSCRIPTION_MANAGER_TRON_ABI = " + JSON.stringify(manager.abi, null, 2) +
    " as const;\n\nexport const SUBSCRIPTION_STATUS_TRON = [\"Inactive\", \"Active\", \"Overdue\", \"Expired\"] as const;\n");
  fs.writeFileSync("../frontend/src/abi/MockUSDCTron.ts",
    "export const MOCK_USDC_TRON_ABI = " + JSON.stringify(usdc.abi, null, 2) + " as const;\n");
'
```
